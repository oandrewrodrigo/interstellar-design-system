# Tokens do Design System Interstellar

Bem-vindo à documentação completa dos tokens do Design System Interstellar.

## Visão Geral

Os tokens são os valores fundamentais que definem a identidade visual do sistema. Eles incluem:

- **Cores**: Paletas completas para diferentes contextos
- **Tipografia**: Sistema completo de fontes, tamanhos e pesos
- **Espaçamento**: Valores consistentes para margens e paddings
- **Border Radius**: Raios de borda padronizados
- **Tamanhos**: Dimensões para elementos e ícones

## Formato dos Tokens

Todos os tokens seguem o padrão [W3C Design Tokens](https://tr.designtokens.org/format/), garantindo compatibilidade e interoperabilidade.
