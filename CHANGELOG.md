# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- ESLint and Prettier configuration for code quality
- Jest and React Testing Library for unit testing
- GitHub Actions workflows for CI/CD
- Accessibility tests using jest-axe
- Comprehensive test suite for Button, Input, and Checkbox components
- CHANGELOG.md for version tracking
- CONTRIBUTING.md for contributor guidelines

### Changed

- Improved code quality with linting rules
- Enhanced component documentation

## [1.0.0] - 2024-11-21

### Added

- Initial release of Interstellar Design System
- Core components: Button, Input, Textarea, Checkbox, Radio, Dropdown, Notification, Icon
- Chat System components: ChatMessage, ChatInput, ChatTopNav, ChatItem, ChatStatus, ChatReaction, ChatTimeIndicator
- Design tokens: Colors, Typography, Spacing, Border Radius, Sizes
- Storybook documentation for all components
- NPM package configuration with ESM and CJS support
- Tailwind CSS integration with design tokens

### Features

- Full React component library
- Type-safe PropTypes validation
- Responsive design tokens
- Accessible components with ARIA attributes
- Comprehensive Storybook stories
- Multiple component variants and states
